# Jeeves Express

Juego de Jeeves Robotics: cruza la ciudad, llega primero al restaurante y entrega los pedidos en las mesas.
Si llegas primero, los clientes te reciben felices; si no, te esperan enojados.

Juega en: https://67plma-rgb.github.io/jeeves-express/

Sitio estático (HTML, CSS y JS sin dependencias). Se instala como app en el celular y funciona sin internet una vez abierto.
